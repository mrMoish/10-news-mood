# NewsMood 📰🎭

Веб-приложение для чтения реальных новостей в разных эмоциональных тональностях (радостно, грустно, иронично и т.д.) без искажения фактов.

🤖 **Разработка:** Проект разработан с помощью AI-ассистента **z.ai**.  
🌐 **Демо:** Приложение уже развернуто на Render: [Ссылка на Render](https://one0-news-mood.onrender.com)

---

### 💻 Как запустить локально
1. Клонируйте репозиторий и создайте виртуальное окружение:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` на основе `.env.example` и добавьте ваш ключ:
   ```env
   OPENROUTER_API_KEY=ваш_ключ_от_openrouter
   OPENROUTER_MODEL=deepseek/deepseek-chat
   ```
4. Запустите сервер:
   ```bash
   uvicorn app.main:app --reload
   ```
5. Откройте в браузере: `http://localhost:8000`

### 📡 Откуда берутся новости
* Источник: публичный RSS-фид Google News на русском языке.
* При старте приложения (если БД пуста) загружается 15 свежих новостей.
* Описание из RSS приходит в виде HTML. Приложение очищает его через **BeautifulSoup4**, сохраняя только текст. Парсинг сайтов-источников не используется, чтобы избежать блокировок и долгих загрузок.

### 🗄️ Хранение данных
* **SQLite + SQLAlchemy**. Две таблицы: `news` (оригиналы + кэш фактов) и `rewritten_news` (AI-версии).
* Ограничение `UNIQUE(news_id, mood)` на уровне БД запрещает дублирование настроений для одной новости.
* **Ленивая генерация:** AI вызывается *только* при первом клике на настроение. При повторном открытии текст мгновенно отдается из базы.

### 🎨 Переписывание тона
1. Пользователь открывает новость и выбирает настроение внутри карточки.
2. Backend извлекает факты (имена, даты, числа) из текста в JSON.
3. DeepSeek получает промпт: изменить *только* эмоции, используя факты как жесткие ограничения.

### 🛡️ Проверка фактов
Одного приказа "не меняй факты" недостаточно, поэтому реализован отдельный конвейер:
* Отдельный AI-запрос (Fact-checker) строго сравнивает оригинал, факты и переписанный текст.
* Если факты искажены (`passed: false`), генерация повторяется (до 3 попыток).
* В UI: успех — "✓ Факты сохранены". Провал — "⚠️ Факты могли быть искажены" и кнопка принудительной перегенерации.

* **Провайдер:** OpenRouter API.
* **Модель:** `deepseek/deepseek-chat`.
